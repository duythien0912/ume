# debug_panel_device

Device info tool for [`debug_panel_core`](https://pub.dev/packages/debug_panel_core): system, app, network, battery, platform and license details in sections that open and close; tap a row to copy it.

## Usage

```dart
PluginManager.instance.register(DeviceInfo());
```
