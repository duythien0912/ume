# debug_panel_device

A renamed fork of [`ume_kit_device`](https://pub.dev/packages/ume_kit_device) from [UME](https://github.com/insightop/ume), published on pub.dev so apps can use it without a git dependency.

Source: https://github.com/duythien0912/ume/tree/ume2/ume2/debug_panel_device

## Changes from `ume_kit_device`

- Package renamed to `debug_panel_device`; the library is `package:debug_panel_device/debug_panel_device.dart`.
- Depends on `debug_panel_core` instead of `ume_core`.
- No other code changes.

## Usage

Same API as `ume_kit_device`. Import `package:debug_panel_device/debug_panel_device.dart` instead of `package:ume_kit_device/ume_kit_device.dart`.
