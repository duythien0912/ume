# ume2_kit_dio

A renamed fork of [`ume_kit_dio`](https://pub.dev/packages/ume_kit_dio) from [UME](https://github.com/insightop/ume), published on pub.dev so apps can use it without a git dependency.

Source: https://github.com/duythien0912/ume/tree/ume2/ume2/ume2_kit_dio

## Changes from `ume_kit_dio`

- Package renamed to `ume2_kit_dio`; the library is `package:ume2_kit_dio/ume2_kit_dio.dart`.
- Depends on `ume2_core` instead of `ume_core`.
- No other code changes.

## Usage

Same API as `ume_kit_dio`. Import `package:ume2_kit_dio/ume2_kit_dio.dart` instead of `package:ume_kit_dio/ume_kit_dio.dart`.
