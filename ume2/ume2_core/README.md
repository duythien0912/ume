# ume2_core

A renamed fork of [`ume_core`](https://pub.dev/packages/ume_core) from [UME](https://github.com/insightop/ume), published on pub.dev so apps can use it without a git dependency.

Source: https://github.com/duythien0912/ume/tree/ume2/ume2/ume2_core

## Changes from `ume_core`

- Package renamed to `ume2_core`; the library is `package:ume2_core/ume2_core.dart`.
- Floating button is 44 x 44 instead of 65 x 65.
- Floating button shows a bug icon (red while the menu is open) instead of the Flutter logo.
- Unused Flutter logo import removed.
- No other code changes.

## Usage

Same API as `ume_core`. Import `package:ume2_core/ume2_core.dart` instead of `package:ume_core/ume_core.dart`.
